## TC-ADM-ALIGN-001: Country/State/District/Pincode row stretches full width in admission form

**Preconditions:**
- User is logged in with permission to create admissions
- Admission form is accessible from `Admission Management > Enquiries > Create Admission`

**Steps:**
1. Open `Create Admission` for any enquiry.
2. Navigate to the address section containing `Country`, `State`, `District`, and `Pincode`.
3. Verify all four fields are aligned in one responsive row on desktop (or split to 2/1 columns on smaller screens per breakpoints).
4. Confirm fields are not compressed to the left and use full available card width.

**Expected Result:**
- The selector block occupies full width of the form row.
- Field controls are visually aligned and consistent with other form rows.

**Status:** NOT TESTED
