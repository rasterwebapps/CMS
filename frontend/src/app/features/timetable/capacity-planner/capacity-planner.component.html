How to plan this term's timetable

  1. Pick the term and cohort above, and Calculate — this shows how many students need Theory/Lab/Clinical seats.
  2. In Cohort Room Allocation's Theory step: if no single classroom fits the whole cohort, plan to split it into sections before building the skeleton.
  3. In the Lab/Clinical steps, adjust target batch size if needed, then pick a venue for each pre-filled batch row — add or remove rows if the computed count doesn't match your case — and Finalize/Commit.
  4. Open Skeleton Builder to place Theory/Lab/Clinical sessions into periods for each subject.
  5. Open Staffing to assign faculty — Theory rooms are picked there, but Lab/Clinical rooms are already fixed from Cohort Room Allocation and can't be changed here.
