How to plan this term's timetable

  1. Pick the term and cohort above, and Calculate — this shows how many students need Theory/Lab/Clinical seats.
  2. Check the Theory card: if no single classroom fits the whole cohort, plan to split it into sections before building the skeleton.
  3. Check the Lab/Clinical batch counts, adjusting target batch size if needed, then use Create Suggested Batches once you know which subject offering they belong to.
  4. Open Skeleton Builder to place Theory/Lab/Clinical sessions into periods for each subject.
  5. Open Staffing to assign faculty and rooms — capacity is checked automatically, and an over-capacity room/lab/clinical venue will be blocked.
